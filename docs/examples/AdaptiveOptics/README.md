# AdaptiveOptics

This group is empty on purpose. It is filled by the adaptive-optics session (deformable mirror, spatial light modulator, tiled
apertures, sensorless correction, temporal shaping), after the `ao` plugin exists; see
[the roadmap](../../design/roadmap-ao-twin-2026-11.md) (S3 and S5).

What will be here: a component gallery, correction of a Zernike aberration with the Zernike decomposition plot and a correction
animation, SPGD and modal search, beam shaping on a full-size panel, coherent tiled-aperture combining and temporal shaping.
Every example follows the same rules as the others: a README with its commands, a hero figure, an animation for each iterative
algorithm, and a final assertion of its key number. Until then the building blocks that exist today are in
[Wavefronts](../Wavefronts/) and in the Python module [`ultrafast.plotting.zernike`](../../reference/python-api.md).
