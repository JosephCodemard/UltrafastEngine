# Gallery

Figures and animations made by the examples. Generated by `python build/gallery.py` from the `hero.png` and `animation.gif` files next to the example READMEs; `python docs/examples/make_all.py` redraws them. Each animation is at most 2.5 MB, each figure at most 300 kB.

## Computing

### [4f correlator](examples/Computing/4f-correlator/README.md)

A scene of five letters on a clutter background, and a matched filter for the letter T in the Fourier plane of a 4f system.

![4f correlator: figure](examples/Computing/4f-correlator/hero.png)

![4f correlator: animation](examples/Computing/4f-correlator/animation.gif)

### [Matrix-vector multiplication by light](examples/Computing/matrix-vector/README.md)

y = A x with A a fixed matrix and x a vector of N complex numbers written on N pixels (amplitude and phase).

![Matrix-vector multiplication by light: figure](examples/Computing/matrix-vector/hero.png)

![Matrix-vector multiplication by light: animation](examples/Computing/matrix-vector/animation.gif)

### [Optical convolution](examples/Computing/optical-convolution/README.md)

The same 4f layout as a convolution engine.

![Optical convolution: figure](examples/Computing/optical-convolution/hero.png)

![Optical convolution: animation](examples/Computing/optical-convolution/animation.gif)

### [Parallelism and time](examples/Computing/parallelism-and-time/README.md)

The same Gaussian blur on N x N pixels (pitch 20 µm; the aperture and the focal length f = N dx² / λ grow with N), done three ways: by the engine, by numpy (two FFTs and a product: the digital way), and "optically" (the light crosses 4 f once, plus an assumed sensor exposure).

![Parallelism and time: figure](examples/Computing/parallelism-and-time/hero.png)

![Parallelism and time: animation](examples/Computing/parallelism-and-time/animation.gif)
