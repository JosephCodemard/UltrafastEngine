## 3. Decisions taken and why (the ones a later reader will ask about)

* **Modulator chromatic rule (S2, spike S3).** A wrapped phase map written at a design wavelength is a real grating only if the phase scales with ω: `chromatic: "opd"`
  does that; `fixedPhase` is achromatic (geometric phase); `index` follows `ω Δn(ω)` for liquid crystals. The spike showed a wrapped map disperses like a grating of the
  same period. `phaseAtDesign` is accepted as an alias of `opd`.
* **No whole-executor streaming, no compile cache (S2).** 1920 x 1080 at 16 stored frequencies fits in 3.6 GB; the process peak is set by the .NET garbage collector
  (2.7-3.4 GB for any block size), not by the propagator; a 128 x 128 trial costs 10 ms including the compile, and the file map (46 ms) was the cost, which callbacks remove.
  Sparse spectral sampling: K = 8-16 gives 1e-3 or better up to 30 rad of phase, K ≥ 32 for 100 rad (spikes.md).
* **The tile source is a source, not an element (S3 advisor).** `ultrafast_ao.tiled_array` builds `initialProfile`; the engine normalises the total power, so N in-phase
  tiles peak at N x a single tile.
* **Sensing in Python (S3).** The lenslet Shack-Hartmann model is NumPy (`control.shack_hartmann`); the bench uses the engine's ideal zonal `wavefrontSensor`. There are no
  `ultrafast ao` CLI commands.
* **One code path for fits (S4, advisor call 1).** A fit without `conditions` is one implicit condition. Held-out conditions are never in the cost; they get chi², curves
  and bands from the same covariance. Priors and smoothness penalties are added once after all conditions. A shared parameter that a condition also `set`s is an error.
* **Network transforms are not PINNs (S4).** A small tanh network whose output layer carries the constraints: `bounded` (sigmoid into a range), `positive` (softplus),
  `monotone` (squared weights, so the output cannot decrease in the variable, also outside the training range); weight decay is the only soft term; weights are boxed
  to ±12 so CMA-ES works. Gradients are finite differences (one run per parameter and condition; the network test needed 1050 runs); analytic adjoints through linear
  elements were not investigated.
* **Validation rules are stated, not tuned (S4).** Flag a held-out condition above 3 x max(1, training chi² per point) or below 80 % coverage inside 2σ; marginal above 1.5 x.
* **Honesty rules held throughout.** A disagreement with a reference is a finding; no tolerance is loosened to hide a failure; round-off is printed as a bound; constants that
  could not be checked are marked unverified.

## 4. Findings (measured; some are open questions, see plan-next.md)

* **Strehl.** The engine's focal peak is 0.5-2.4 % above the exact on-axis value `|<a e^{iφ}>|²` for symmetric aberrations; Maréchal `exp(-σ²)` is within 1 % at σ = 0.25 rad and
  5 % at 0.5 rad. DM bench: 10 x 10 actuators, defocus + astigmatism + coma (0.3 / 0.2 / 0.15 waves rms) go from Strehl 0.31 to 0.87 zonal and 0.965 modal.
* **SLM.** Blaze efficiency within 0.6 % of the sampled staircase (N = 4, 8, 16); at other wavelengths within 1.5 % of the `s(λ)` law. In the engine the focal plane is sampled at
  the simulation pitch: `f = N dx² / λ` makes focal pixels the hologram's FFT bins; patterns must stay in the inner half of the window. Engine against the Fourier prediction
  (with the |sinc|² pixel envelope): correlation 0.98-0.99 (open: why not 0.999). The generic liquid-crystal Δn preset is **unverified**.
* **Quantisation in the GS loop** helps at 2 and 3 levels (6 of 6 seeds), not at 4 or 8 on the ring target.
* **Shaper.** Weiner side pulses of a gapped mask: energy ratio `[sin(πf)/(πf)]² exp(-2(π w0/p)²)` within 1 % (measured 0.0159 against 0.0159 in the example); the planner does not know a
  shaper's time extent, so `grid.windowS` must cover `2π / pixel bandwidth` and a large programmed GDD can wrap round the window without a warning.
* **Tiled arrays.** Tile delay cost 0.3 %, 0.04 %, 0.65 % from the Gaussian-overlap formula (rms 10, 25, 40 fs, 30 fs pulse); SPGD with 16 channels locks to 1.000 at gain 10 (gain 20
  diverges). In the example the locked axis fluence is 1.02 of the in-phase reference (open).
* **SPGD gain** (sensorless example): 1.5 gives Strehl 0.64, 3 gives 0.95, 5 gives 0.80 in 80 iterations.
* **Transmission matrix.** Phase-stepping from intensities alone is exact to 1e-9 rad; focusing enhancement 50.40 against `(π/4)(N - 1) + 1` = 50.48 (3000 outputs, N = 64); through the engine with a
  Gaussian beam 47.5 against the unequal-amplitude expectation 50.0.
* **Twin.** On the synthetic lab: 1.6 s, 135 runs; centre 1033.008 nm (truth 1033), FWHM 8.497 nm (8.5), slope 2.9998 rad/µJ (3.0); coverage inside 2σ 94-98 %; the saturating lab's held-out
  chi² per point is 11.9 and 180, verdict `fits-training-only`. The information about a nonlinear-phase slope is **not monotonic in energy** (fringes finer than the 0.2 nm resolution lose it);
  a zero-energy shot shrinks the slope's uncertainty most because it pins the correlated filter parameters. A drift tracker needs the expected drift in physical units (0.3 nm followed a
  0.5 nm shift in one update; the fitted sigma, 0.006 nm, followed 17 % in three).
* **Fibres.** N = 1 soliton within 0.03 % over two periods; N = 3 back to 1.003 x at z0 = (π/2) L_D; pure-SPM bandwidth growth 8.85 x equals `sqrt(1 + 4φ²/(3√3))`; Raman shift rate scales as T0^-4.3
  (Gordon: -4) but is 16-36 % above Gordon's formula with the model's T_R (open).
* **cw against pulse.** A pulse's stored frequency is within 1e-7 of the carrier; a cw source's single bin is snapped to the lattice, 1.2e-6 off the requested carrier, so cw and pulse focal patterns agree to
  3e-6, not the 1e-9 the plan asked for (open).
* **Brief items met differently:** the pulse through a wrapped ramp is three monochromatic runs against `s(λ)`; the (π/4)(N - 1) + 1 test is NumPy plus the engine example (no engine scatterer test); FROG / d-scan is not wired as a
  closed-loop metric (any function of a run works).

## 5. Known limits of what was built

Idealised devices (no hysteresis, creep, thermal drift, polarisation dependence or flicker; no segmented or bimorph mirror kinds); the shaper is the 1-D transfer function with a field-overlap spot model and no
spatial chirp (TS3); a callback map is evaluated once per run; `outsideTransmission` defaults to 0 so a small DM in a big grid clips the beam; a grid cell split between two device cells transmits less than 1
(spatial frequency the grid cannot carry); the tile source has one radius and a simple shape per array, no mode-field profile, no core-to-core coupling; modal fit uses the gradient at the lenslet centre (a bias for
Noll ≥ 7); the only twin template is the synthetic spectral lab; `ultrafast twin` needs `ULTRAFAST_PYTHON` set to a Python with NumPy.

## 7. MCP server: the agreed design (not built)

Hand-written JSON-RPC 2.0 over newline-delimited stdio; no `mcp` dependency (so no `ultrafast[mcp]` extra). Check the current MCP specification for the `protocolVersion` string and
message shapes before writing. Refusals are results with `isError: true`; unknown methods give -32601; notifications get no reply.

* **Eight tools:** `describe`, `validate`, `run`, `compare_to_measured`, `scan`, `fit`, `explain_warning`, `plot`; workspace-scoped, read-only with respect to any lab hardware.
* **Worker.** Engine work runs in a persistent worker subprocess with its own stdout (the .NET host may write to fd 1). On overrun the worker is killed and respawned and the server keeps serving. A
  pre-flight estimate (runs x grid points) refuses up front. Memory: `DOTNET_GCHeapHardLimit` in the worker (verify it is honoured by hosted and AOT) plus caps on N and nx·ny·spectralSamples from the spike
  numbers; not `RLIMIT_AS`. The worker starts with `ULTRAFAST_HOME` set to an empty private folder so `~/.ultrafast/plugins` is not loaded (a plugin allow-list in the engine would be the proper fix).
* **Refuse by default:** strings starting with `@`, and every callback / python / expression / user kind (take the list from `Schema/BuiltIn*.cs`, not from memory); `set` is narrowed to roots `pulse/`,
  `element:`, `instrument:` and never `type`, `kind`, `measured`, `file`; values are finite numbers or identifier-pattern strings; every file-valued string must resolve inside the workspace and is
  rewritten to an absolute path (also in `twin.json` and the fitted files); names the server writes match `^[A-Za-z0-9_-]{1,40}$`; unknown arguments are rejected.
* **Tests:** `tools/list` returns eight tools; refusal tests for an expression, an `@name`, a callbacks / fields argument, `../x.csv`, an absolute path, a symlink out of the workspace, and a call over its
  time budget (the next call must still work).

## 8. Lessons that cost time

* A `.gitignore` rule such as `results/` can hide a new Python package (CI caught it); after moving folders grep for `".."`, `parents[` and run the examples without `PYTHONPATH` set.
* A script whose output is quoted in a README must print no wall time; `example_check.py` runs **every** line of a ```` ```bash ```` block, so figure scripts need `# optional:`.
* Run the Python tests without `ULTRAFAST_STRICT_OPTIONS` (an old test writes a snake_case key); set `ULTRAFAST_LIBRARY` to the hosted engine, because a stale `bin/native` lacks the S2/S3 keys.
* The wavefront sensor reports noise outside the beam; mask the lenslets without light. A hook blocks shell commands that touch `bin/` paths.
