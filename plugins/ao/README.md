# ao plugin

Parametric deformable mirror, spatial light modulator, spectral shaper and AOPDF elements (C#, `src/`), with a Python module
(`python/ultrafast_ao`) and algorithms in `ultrafast.algorithms` (`holography`, `control`, `sensorless`). No vendor data.

Documentation: [docs/plugins/ao.md](../../docs/plugins/ao.md). Tests: `AoDeviceTests` (C#), `python/tests/test_ao_*.py`.
